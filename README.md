# PROYEC_FARMAFIND

FarmaFind es un proyecto académico del curso Arquitectura de Software. Su objetivo es permitir la búsqueda de medicamentos disponibles en farmacias, la consulta de precio, ubicación y stock, y la reserva temporal de medicamentos.

Este repositorio organizará la documentación, arquitectura, diseño de software y avances técnicos del proyecto según las guías del laboratorio.
