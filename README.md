# PROYEC_FARMAFIND

FarmaFind es un proyecto académico del curso Arquitectura de Software. Su objetivo es permitir la búsqueda de medicamentos disponibles en farmacias, la consulta de precio, ubicación y disponibilidad referencial con fecha de última actualización, y la solicitud de reservas temporales sujetas a confirmación física por la farmacia.

El MVP propuesto incluirá registro manual e importación obligatoria de Excel (.xlsx/.csv), con vista previa, validación y mapeo de columnas al catálogo general. Para el MVP, la importación será atómica por archivo: si una fila es inválida o no está conciliada, no se guardará ninguna; se presentará un reporte de errores para corregir y reintentar. Cada farmacia administrará sus precios y existencias; FarmaFind supervisará. Pagos e integración automática con inventarios externos quedarán fuera del MVP.

Este repositorio organizará la documentación, arquitectura, diseño de software y avances técnicos del proyecto según las guías del laboratorio.
