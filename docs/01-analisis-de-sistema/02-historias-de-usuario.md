# Historias de usuario del sistema FarmaFind

| Código | Actor | Historia de usuario |
|---|---|---|
| HU01 | Cliente | Como cliente, quiero buscar medicamentos por nombre comercial o principio activo y ver las farmacias que los tienen disponibles para encontrar rápidamente dónde conseguirlos. |
| HU02 | Cliente | Como cliente, quiero consultar la disponibilidad, precio referencial, ubicación y ordenar los resultados por cercanía, precio o disponibilidad para elegir la farmacia más conveniente. |
| HU03 | Cliente | Como cliente, quiero reservar temporalmente una cantidad disponible del medicamento y consultar el estado de mis reservas para asegurar el producto antes de ir a la farmacia. |
| HU04 | Personal de farmacia | Como personal de farmacia, quiero confirmar la entrega de un medicamento reservado para registrar que la reserva fue atendida correctamente. |
| HU05 | Administrador de farmacia | Como administrador de farmacia, quiero registrar y actualizar medicamentos, precios y stock para mantener disponible y correcta la información de mi farmacia. |
| HU06 | Administrador de FarmaFind | Como administrador de FarmaFind, quiero gestionar farmacias participantes, notificaciones y el pago opcional para administrar las funciones complementarias de la plataforma. |
